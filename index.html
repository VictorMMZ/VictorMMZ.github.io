Sobre mí

Soy Víctor, Full‑Stack Developer especializado en backend, con experiencia construyendo APIs robustas, lógica de negocio clara y arquitecturas eficientes usando PHP y Laravel. También desarrollo interfaces modernas y funcionales con JavaScript, React, HTML, CSS y Bootstrap, manteniendo un estilo visual limpio y futurista. Me apasiona resolver problemas reales mediante código bien estructurado, flujos lógicos sólidos y proyectos que combinan rendimiento, claridad y una experiencia visual coherente. Mi objetivo es crear soluciones completas: desde la base técnica hasta la interfaz final.
